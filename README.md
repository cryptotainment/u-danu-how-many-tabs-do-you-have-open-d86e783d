# How Many Tabs Do You Have Open?

Entry for the make.fun bounty [u-danu-how-many-tabs-do-you-have-open-d86e783d](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

`main.py` (Python 3.13, stdlib only) writes one number, digits only, to `/output/entry.txt`. The count is **137** — oddly specific, not a round number: it reads as a real, lived-in count from a tab hoarder, far above what the field would guess, yet entirely believable (unlike a cartoonish 9999). Deterministic: two runs produce byte-identical output (sha256 `d80eae6e96d148b3b2abbbc6760077b66c4ea071f847dab573d507a32c4d99a5`).
